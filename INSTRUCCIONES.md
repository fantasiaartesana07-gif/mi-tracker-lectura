# 📚 Mi Tracker de Lectura

## Cómo subir esto a internet (desde el celular)

### Paso 1 — Crear cuenta en GitHub
1. Entra a **github.com** desde Chrome
2. Toca "Sign up" y crea tu cuenta gratis

### Paso 2 — Subir el proyecto
1. En GitHub toca el **+** → "New repository"
2. Nómbralo `mi-tracker-lectura`
3. Marca "Public" y toca "Create repository"
4. Toca "uploading an existing file"
5. Sube TODOS los archivos de esta carpeta (incluyendo la carpeta `src/` y `public/`)

### Paso 3 — Publicar con Vercel
1. Entra a **vercel.com** → "Sign up with GitHub"
2. Toca "Add New Project"
3. Selecciona tu repositorio `mi-tracker-lectura`
4. Deja todo como está y toca **"Deploy"**
5. En 2 minutos te da una URL tipo `mi-tracker-lectura.vercel.app` ✅

### Paso 4 — Instalarla en tu Android
1. Abre la URL en **Chrome**
2. Toca los **tres puntos** (⋮) arriba a la derecha
3. Toca **"Añadir a pantalla de inicio"**
4. ¡Listo! Aparece como una app con su ícono 🎉
